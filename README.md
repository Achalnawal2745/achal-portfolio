## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Achalnawal2745/achal-portfolio.git
   cd achal-portfolio
   ```

2. **Launch with any local web server**:
   * **Using Python 3**:
     ```bash
     python -m http.server 8000
     ```
   * **Using VS Code Live Server**: Open `index.html` and click **"Go Live"**.
   * **Directly in Browser**: Double click `index.html` to open directly in Chrome/Edge/Firefox.

3. **Deploy to GitHub Pages**:
   - Push code to `main` branch.
   - Go to **Repository Settings** ➔ **Pages** ➔ Set Branch to `main` (`/root`).
   - Site builds automatically at: `https://achalnawal2745.github.io/achal-portfolio/`
